## 6. Content Production System

### Weekly Production Template

**Per week:**
- 4 meme-style educational short videos
- 2 practical technical breakdowns
- 2 behind-the-scenes demo clips
- 2 story-driven reels with a lesson
- 1 longer YouTube tutorial or “problem solved” video

### Production Pipeline
```
1. Topic selection
2. Script writing
3. Hook sentence
4. Visual demonstration
5. Punchline / meme moment
6. CTA (Watch full video / DM / Book / Buy)
7. Edit + caption + upload
8. Track retention + engagement
9. Improve next post based on view retention
```

### Hook Formula
```
Problem + Emotions + Tiny Lesson + Punchline
Example:
"My TV went off during a storm and everyone blamed electricity. Here’s the real reason — and it’s a ₦3,000 fix."
```

## 7. Real-Time Analytics Payload

### Each piece of content must track:
- platform
- content type
- topic
- publish time
- views
- watch time
- shares
- saves
- comments
- profile visits
- clicks to website
- clicks to WhatsApp
- clicks to offers page
- purchases generated

### Analytics Payload Example
```json
{
  "content_id": "tech-001",
  "platform": "youtube",
  "title": "Why your microwave keeps tripping the breaker",
  "type": "short_video",
  "views": 1240,
  "watch_time": 3422,
  "shares": 94,
  "saves": 61,
  "profile_visits": 32,
  "website_clicks": 7,
  "whatsapp_clicks": 5,
  "offer_clicks": 2,
  "purchases": 1,
  "amount_ngn": 22000,
  "timestamp": "2026-10-09T12:00:00Z"
}
```

### Metrics to compute
- CTR = offer click / views
- conversion rate = purchases / clicks
- revenue per content piece = amount generated / content published
- save rate = saves / views
- retention = average watch time / total length
