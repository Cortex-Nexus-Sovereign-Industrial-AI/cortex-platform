## 2. Trigger & Automation Layer (Bridge)

**Flow:**
Frontend Event → HTML Injector Bridge → Webhook Router → Processing Core → Logging / Notification

- **HTML Injector Bridge**  
  Captures events and sends structured JSON payloads (zero-config test module available).

- **Middleware Router**  
  Zapier / Make.com / n8n (prefer free tier for now).

- **Processing Core**  
  Lightweight Python or Node scripts for transformation and routing.

- **State & Logging**  
  GitHub repositories + optional Telegram alerts.

**Design Principle:** Stay on free tiers as long as possible. Human only confirms financial actions.
