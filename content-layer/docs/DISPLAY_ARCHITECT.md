# Display Architect Rules — Every Playback, Every Life

Rules that govern the UI and session display for the Cinis Nexus A18+ Content Layer.

1. **Professional knowledge first** — status and copy always signal Knowledge Priority ON.
2. **Ephemeral only** — no secrets, no permanent keys, no private data in the client.
3. **Shadow-Vault spirit** — isolation language and badges (A18+, Platinum, API Pipelines, X-Connected Server).
4. **Playback consistency** — every session start/end updates status clearly; tools surface in console for pipeline runs.
5. **History aware** — product lineage and scaffold history live in-repo so any connected run can cite origin.
6. **Channel ready** — display never pretends content is “done”; tools prepare packages for deploy_content_channel.
7. **Visible** — branding, badges, and footer (Cortex HRbot · Cinis Nexus) keep the product recognizable across media.

These rules apply to every future scaffold or playback of this content layer.
