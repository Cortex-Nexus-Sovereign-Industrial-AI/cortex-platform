Event vocabulary

page_view

Public page viewed.

path_selected

Learning, technical skills or project enquiry path selected.

enquiry_started

A visitor begins an enquiry.

enquiry_qualified

Enough information exists for routing.

offer_presented

An appropriate service or product is presented.

payment_confirmed

Authoritative payment confirmation received.

delivery_completed

Requested deliverable completed.

follow_up_due

Operational follow-up is required.

Control boundary

What the engine will not do

No fabricated metrics

Counts and conversion rates appear only when a real data source supplies them.

No browser payment authority

A client-side success event never replaces authoritative payment verification.

No secret exposure

API keys and payment secrets remain server-side environment variables.

No unnecessary personal data

Operational telemetry is minimized to what is needed for routing and service delivery.
