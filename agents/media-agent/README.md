# Media Agent

This folder is for social-ready, SEO-friendly, and public-facing media generation.

## Goal
Convert the repo's platform knowledge into short-form marketable snippets.

## Output types
- teaser copy
- social snippets
- landing page blurbs
- metadata and summaries
- support content for public surfaces

## Use cases
- social posts
- website highlight cards
- member update announcements
- content funnel entry points

## Primary rule
Any public output must stay aligned to `IDENTITY.md`, the official site, and the brand story.
