# SOP — Payment Received → Brief → Delivery
**Offer:** 30-Day AI Content System (₦22,000)  
**Brand:** Cortex Intelligence Nexus  
**Updated:** 2026-08-16

---

## 1. Payment Confirmation
- Customer pays via the Paystack link you sent.
- Confirm success in:
  - Paystack Dashboard → Transactions, or
  - Netlify function logs / webhook (`charge.success`)
- Reply immediately with the “After payment” message from the WhatsApp script and request the brief.

## 2. Brief Collection
Required fields:
1. Brand / page name
2. Niche + audience
3. Platforms
4. Tone
5. Samples / link (optional)

Do not start the 5-day clock until the brief is received.

## 3. Delivery Clock
- Start: moment full brief is in hand.
- Target: within 5 calendar days.
- If delivery will miss the window → proactively offer full refund or agree new date in writing.

## 4. Build & Deliver
Deliverables:
- Personalized 30-day content calendar
- 30 ready-to-post captions or outlines
- Weekly rhythm guide
- 25 niche-specific hooks
- Short setup note

Delivery method: WhatsApp + secure Drive/PDF link (or preferred channel).

## 5. Revision Window
- One revision pass within 7 days of delivery.
- After 7 days the order is closed unless founder decides otherwise.

## 6. Order Cap & Tracking
- Recommended hard cap: 5 concurrent active mid-ticket orders.
- Track in a simple private list or spreadsheet:
  - Customer name / handle
  - Payment reference
  - Brief received date
  - Due date
  - Status (Paid / Briefed / In Progress / Delivered / Closed)

## 7. Refunds
- Full refund only if not delivered within the promised 5 days (delivery guarantee).
- No refunds for “results” (followers, sales, etc.) — this is stated in every script.

## 8. Ethics Guardrails
- Never promise income, follower growth, or sales numbers.
- Never share customer briefs or delivered assets publicly without permission.
- Keep all secret keys out of chat, screenshots, and Git.

---

This SOP keeps money, promises, and delivery quality under founder control while the platform infrastructure (webhook, store, scripts) runs automatically.
