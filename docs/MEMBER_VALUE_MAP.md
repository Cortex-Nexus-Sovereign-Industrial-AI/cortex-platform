## Soft problem → solution framing

Problems the platform is built to ease (honest, regional):

1. **Hard to find local contacts** → Directory (searchable, expandable)
2. **Skills gap in digital / AI / agri-business** → Education hub tracks
3. **Missed funding or programme notices** → Alerts section (progressive)
4. **Payment without a home** → Success page → member dashboard
5. **Fragmented docs** → PLATFORM_STRUCTURE, ACCESS_FLOW, this map

No income guarantees. Deliverables and access only.
